The room goes dark, the frame stays lit.

Carbon Arc is a single-purpose dark theme for a 24-inch screen at arm’s length. The chrome is graphite and quietly stepped; the signal is one low-chroma warm tone, used for four things only. Nothing in the interface is brighter than the picture you are looking at.

  • no pure black ground, no pure white text
  • one signal tone, in four places: active, focus, stars, playhead
  • no shadow anywhere except floating surfaces
  • no motion on hover beyond a surface tone change
  • no mobile breakpoints — this is one screen size, on purpose

01 / premise

A library app is a dark room with a bright rectangle in it. Design the room, not the rectangle.

Stash is used at night, close to the screen, for long sessions of scanning thumbnails and judging them. That gives one hard constraint: the interface must never compete with the imagery. Pure black is out — it turns every thumbnail edge into a hard cut-out and makes thin text shimmer. So the base is graphite: dark enough to disappear, light enough that a 1 px hairline still reads and card edges dissolve into the field instead of being drawn.

The second constraint is a single warm signal. Warmth in a dark UI reads as lamplight, and lamplight is exactly the metaphor — but warmth spread across the screen becomes a wash. So the warm tone is rationed to four jobs: the active nav underline, the focus ring, filled rating stars, and the playhead. Everything else is neutral.

The third is hierarchy by luminance, not by colour. Five surfaces, two hairlines, three text steps. A card is legible against the canvas because it is 5 L* lighter, not because it has a border and a shadow. Menus float because they are the lightest surface plus a soft shadow — the only place a shadow is allowed.

The typography carries the rest. All numbers — durations, counts, resolutions, dates, file paths — are monospaced, so a row of cards aligns on its data instead of its prose. That one decision does more for scanability than any amount of card polish.

  • densityRow height 30 px in the rail, 40 px in tables, 32 px for controls. Nothing goes below 28 px: this is pointer-only, but a 24-inch screen is still read at 60 cm.
  • columnsGrid is auto-fill, minmax(212px, 1fr) — five columns at 1920, four at 1440. The rail never collapses and never overlays; it is fixed furniture, so the eye can learn one layout.
  • vertical rhythmSections of the detail page step in 8 / 16 / 24 / 32. There is no spacing above 48 inside the app; large gaps on a desktop read as missing content.
  • proseDescriptions cap at 68 characters. Long metadata (paths, hashes) is mono and allowed to truncate with a middle ellipsis plus a tooltip.

08 / coverage

What the plugin stylesheet has to reach.

Stash ships Bootstrap 5 under a set of hand-authored SCSS classes, so a theme cannot be done by variables alone. The plugin needs both: a token layer on :root that remaps the framework variables, and selector overrides where colours are hard-coded. Everything below is what “complete” looks like.

Every surface the app sits on, and the one accent line that tells you where you are.

09 / self check

What this deliberately is not.

rejected

  • Pure black + neon. The default “gamer dark”: crushing blacks, one saturated accent, glow on hover. It fights every thumbnail.
  • Stash’s own blue graphite. #202B33 with #137CBD is the built-in Blueprint palette; a theme that lands near it has not made a decision.
  • Warm paper-and-ink. Beautiful, but already taken by Flexoki and it turns the grid into a document. Carbon Arc keeps the shell cool and spends warmth only on the signal.
  • Glass panels, blur, gradients on cards. Each one adds a bright edge; at 24 inches they read as smudges over the imagery.

kept

  • A five-step surface ladder. Elevation is luminance; borders confirm, never draw.
  • One signal, four jobs. Active underline, focus ring, stars, playhead.
  • Mono for all numbers. Card rows align on data; file paths and durations stop jittering.
  • Bone instead of white. #E6E4DE at 13:1 — legible without the halo that #FFF gets on dark.
  • Bone-filled primary buttons. The clearest possible “next action”, with zero colour saturation.

open questions

  • Signal hue. Brass is the proposal; patina and dusk are already tokenised. Pick one before writing the CSS — the swap is three variables.
  • Root size. 15 px assumes 1920×1080 at 24 in. On a 1440p 24-inch panel, drop to 14 px and raise the grid minimum to 230 px.
  • Login page. Stash does not load plugins there; it needs the same tokens pasted into Interface → Custom CSS, or it will flash a default blue-grey form.
  • Third-party plugins. Overlay plugins that hard-code colours will need a small compatibility block, as with any theme.
